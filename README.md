# mathman
Just your average math nerd... or not.

Slackbot functions:
- 
 - /mathman-ping: checks bot latency
 - /mathman-help: gives a list of all bot commands
 - /mathman-catfact: gives a random fact about cats
 - /mathman-derive: derives a function
 - /mathman-factor: factorises a function
 - /mathman-integrate: integrates a function
 - /mathman-zeroes: gets the zeroes of a function
 - /mathman-simplify: simplifies a function (e.g. 3x+3x^2-x^2+2x = 2x^2+5x)
